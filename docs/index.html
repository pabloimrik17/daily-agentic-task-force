Stonks personal

Tus registros de inversión, en acuerdo con tu cartera.

Stonks es un plugin de Claude Code en desarrollo dentro de Daily Agentic Task Force. Su propósito es comparar una hoja de seguimiento de Google Sheets con posiciones y órdenes de Interactive Brokers y otros registros que mantienes, para señalar discrepancias en un informe.

El plugin todavía está en desarrollo. Esta página documenta la integración personal de Google Sheets que lo acompaña.

Qué acceso pide a Google

La integración utiliza Google Workspace CLI (gws) para leer las celdas de la hoja y pestaña que configuras. El único permiso solicitado es spreadsheets.readonly: permite ver las hojas de cálculo accesibles a tu cuenta. El permiso de Google no queda limitado a una sola hoja, aunque Stonks utiliza la que indicas en su configuración.

No solicita permisos de Gmail ni de edición de Drive o Sheets. No crea, modifica ni elimina hojas de cálculo. La conexión es voluntaria y puedes revocarla desde tu cuenta de Google.

Cómo se usan los datos

Los datos se utilizan para preparar el informe de seguimiento. El motor se ejecuta en tu ordenador; los informes y datos expuestos a Claude Code pueden ser procesados por el proveedor de IA según tu cuenta y sus ajustes. Esta web solo contiene documentación y no recibe datos de tu cartera.

Consulta la política de privacidad antes de conectar tu cuenta.
