Stonks personal

Actualizada el 4 de octubre de 2026.

Esta política describe la integración personal de Google Sheets prevista para Stonks, un plugin de Claude Code en desarrollo mantenido por pabloimrik17 en Daily Agentic Task Force. Se aplica a esa integración y a esta web de documentación; los servicios externos tienen sus propias condiciones.

Acceso a Google Sheets

Con tu consentimiento, Google Workspace CLI (gws) obtiene acceso con el permiso https://www.googleapis.com/auth/spreadsheets.readonly. Google permite leer las hojas de cálculo accesibles a la cuenta autorizada; este permiso no queda restringido a un único archivo o pestaña. Stonks lee la hoja y pestaña indicadas por ti para obtener los registros de seguimiento: símbolos, estados, cantidades, precios y otros valores presentes en el rango configurado.

La integración no solicita acceso a Gmail ni permisos para editar Google Sheets o Drive. No crea, modifica ni elimina hojas de cálculo.

Finalidad y procesamiento

Los datos se usan para comparar tus registros de seguimiento con las otras fuentes que conectas, detectar discrepancias y generar informes dentro de Claude Code. No se venden ni se utilizan para publicidad.

El motor de comparación se ejecuta en tu ordenador. Los datos e informes que se expongan como resultados de herramientas, mensajes o contexto de Claude Code pueden enviarse a Anthropic o al proveedor de modelos que hayas configurado. Su procesamiento, conservación y posible uso para mejora de modelos dependen del producto, contrato y ajustes de esa cuenta. Revisa esos ajustes antes de utilizar datos personales o financieros. Consulta la política de Anthropic; sus ofertas empresariales se rigen por los acuerdos aplicables.

Esta integración no publica datos de Sheets en GitHub ni en esta web y no tiene un servidor propio que reciba tus registros. El acceso a Google se realiza mediante sus APIs. Las conexiones que autorices con otros servicios, como Interactive Brokers, se rigen también por sus condiciones.

Almacenamiento y eliminación

La configuración, capturas e informes de ejecución se guardan en tu ordenador. El diseño del plugin prevé estado bajo ~/.local/state/stonks o la ubicación que configures. La conservación local y la limpieza dependen de la versión del plugin; puedes borrar esos archivos cuando ya no los necesites. Los historiales de Claude Code y del proveedor de IA se gestionan por separado mediante las opciones de esos productos.

El cliente OAuth de Google se guarda en tu equipo. Si lo sincronizas con chezmoi, el repositorio contiene únicamente su copia cifrada con age. Los tokens se mantienen en el almacén cifrado de gws; en macOS la clave de cifrado se conserva en el Keychain. No se incluyen tokens ni datos financieros reales en el código, ejemplos o fixtures del proyecto.

Revocar el acceso

Puedes retirar el permiso desde las conexiones de terceros de tu cuenta de Google, seleccionando tu aplicación OAuth y eliminando su acceso. La revocación impide nuevas lecturas con ese permiso; no borra por sí sola informes, capturas o conversaciones existentes. Elimina también las copias locales y los historiales que quieras retirar.

Visitas a esta web

Estas páginas no incorporan analítica, formularios, scripts de seguimiento ni recursos de terceros. GitHub Pages presta el alojamiento y registra información técnica, incluida la dirección IP, por motivos de seguridad. Consulta la política de privacidad de GitHub.

Contacto y cambios

Para consultas sobre el proyecto o esta política, contacta con pabloimrik17 mediante las incidencias del repositorio. No incluyas secretos ni datos financieros en mensajes públicos. Esta política se actualizará cuando cambie el uso de los datos; la fecha de actualización aparece al principio.
